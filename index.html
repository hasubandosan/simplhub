Синхронизация с GitHub

Список хранится в одном JSON-файле в вашем репозитории. Каждое изменение — отдельный коммит через GitHub Contents API. Нужен Fine-grained token с правом Contents: Read and write только на этот репозиторий.

→ Создать токен
⚠️ Токен сохраняется в localStorage этого браузера. Не открывайте страницу на чужих устройствах и не публикуйте токен. При утечке — сразу отзовите его в настройках GitHub.
